# Dependencies

Every direct dependency in the repository, why it is here, what else was considered and which
playbook instruction added it. This follows the Master Context rule "never add dependencies
without telling me why".

From now on, whoever adds, removes or replaces a direct dependency updates its row in the same
commit. Versions are not repeated here; the `package.json` files and the pnpm catalog in
`pnpm-workspace.yaml` are the source of truth.

| ---------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ----------- |
| `typescript`                       | root, shared, api, web | Type checking everywhere; compiles packages/shared and the API to `dist/`. Pinned to ~6.0 (see DECISIONS).                                                                           | TypeScript 7 native port (not yet supported by typescript-eslint).                                       | #1          |
| `@types/node`                      | root, api, web         | Node.js type definitions. | `eslint`                           | root                   | Linting with zero warnings allowed. | `@eslint/js`                       | root                   | ESLint's recommended JavaScript rules.                                                                                                                                               | None; it is ESLint's own package.                                                                        | #1          |
| `typescript-eslint`                | root                   | TypeScript parser and the type-aware `strictTypeChecked` and `stylisticTypeChecked` rule sets.                                                                                       | None with type-aware rules.                                                                              | #1          |
